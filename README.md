## The pitch

> A smoke detector that only beeps when its battery is perfectly fine, just to remind you it could quit at any moment.

One sentence, 116 characters. A smoke detector that inverts its own purpose: instead of warning you when the battery is dying, it beeps only while everything is fine — a tiny, passive-aggressive reminder that it could quit at any moment.

## How it works

`main.py` writes the pitch to `/output/entry.txt` and verifies the bytes on disk match exactly. It asserts the entry is one sentence (1–220 characters, exactly one full stop).

```sh
python3 main.py
cat /output/entry.txt
```
